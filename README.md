# Learning LLMs

A research-oriented journey through Large Language Models, from the mathematical foundations of language modeling to modern LLM architectures, training, reasoning, retrieval, agents, interpretability, and efficient systems.

## Approach

For each major concept:

1. **Learn** — understand the mathematical and conceptual foundations.
2. **Implement** — build the idea from first principles where practical.
3. **Experiment** — measure its behavior and test its assumptions.
4. **Write** — explain what was learned in my own words.
5. **Read** — connect the concept to research papers.
6. **Reproduce** — implement important research ideas.
7. **Question** — identify limitations and possible research directions.

The emphasis is on understanding *why* things work, not merely using existing libraries.

## Topics

* Language modeling and information theory
* Transformers and attention
* Tokenization
* LLM pretraining and scaling
* Post-training and preference optimization
* Parameter-efficient fine-tuning
* Retrieval-Augmented Generation
* Knowledge Graphs + LLMs
* Reasoning and test-time compute
* LLM agents
* Interpretability
* Evaluation
* Efficient training and inference
* Frontier LLM research


The learning material may initially be scattered. The `book/` directory is intentionally kept separate so that the final structure can evolve without constraining exploration.

## Philosophy

> Learn it. Implement it. Measure it. Explain it. Try to break it.

This repository is a record of that process.
